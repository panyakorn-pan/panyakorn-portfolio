# เว็บพอร์ตของปัณยกร

เว็บนี้ทำด้วย HTML + CSS + JS ธรรมดา ไม่มี framework ไม่ต้อง build อะไรทั้งนั้น
เปิดไฟล์ `.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม (มี VSCode ก็พอแล้ว)

## เว็บมีกี่หน้า อะไรอยู่ตรงไหน

- `index.html` → หน้าแรก
- `portfolio.html` → หน้า **Hall of Frame** (โชว์การ์ดผลงานทั้งหมด)
- `project.html` → หน้ารายละเอียดผลงาน (ไฟล์เดียว ใช้ซ้ำกับทุกผลงาน มีสไลด์รูปในตัว)
- `about.html` → หน้า **My Profile** (แนะนำตัว/ทักษะ/การศึกษา)
- `css/style.css` → คุมหน้าตา สี ฟอนต์ ทั้งเว็บ
- `js/projects-data.js` → **ไฟล์สำคัญ** เก็บข้อมูลผลงานทั้งหมด (ชื่อ คำอธิบาย รางวัล รูป)
- `js/script.js`, `js/portfolio.js`, `js/project.js` → ไฟล์ลูกเล่น ปกติไม่ต้องไปยุ่ง
- `images/` → เอารูปมาวางตรงนี้

## เปิดดูเว็บยังไง

1. เปิดโฟลเดอร์นี้ด้วย VSCode
2. ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ตรงๆ ได้เลย **หรือ**
3. ถ้าอยากเห็นการแก้ไขอัปเดตสดๆ ให้ลง extension **Live Server** ใน VSCode (ฟรี) แล้วคลิกขวาที่ `index.html` เลือก "Open with Live Server"

## อยากใส่รูป ทำยังไง

เว็บนี้มีจุดใส่รูป 2 แบบ วิธีไม่เหมือนกันเป๊ะ ดูตามนี้เลย

### แบบที่ 1 — รูปหลักของหน้าแรก (รูปตัวเอง, รูปพรีวิว 2 บล็อก)

ตอนนี้จุดพวกนี้ยังเป็นกล่องลายทางเทาๆ เขียนบอกไว้ว่าต้องเอารูปไปวางที่ไหน เช่น `[Edit here: add your photo at images/hero.jpg]`

ทำตามนี้ทีละขั้น:
1. เตรียมรูปที่จะใช้ แล้วเปลี่ยนชื่อไฟล์ให้ตรงกับที่กล่องบอกไว้ (เช่น ตั้งชื่อว่า `hero.jpg`)
2. ลากไฟล์รูปไปวางในโฟลเดอร์ `images/`
3. เปิดไฟล์ `.html` ที่เกี่ยวข้อง (เช่น `index.html`) ด้วย VSCode
4. หาโค้ดที่ขึ้นต้นด้วย `<div class="media-placeholder">` แล้วลบทั้งก้อนทิ้ง (ลบยาวไปจนถึง `</div>` ที่ปิดคู่กัน)
5. ใต้ก้อนที่ลบไป จะมีบรรทัดคอมเมนต์แบบนี้อยู่ `<!-- <img src="images/hero.jpg" ...> -->` ให้ลบแค่ `<!--` กับ `-->` ที่ครอบหัวท้ายออก เหลือแค่ `<img src="images/hero.jpg" ...>` เฉยๆ
6. เซฟไฟล์ แล้วรีเฟรชหน้าเว็บ รูปจะโผล่มาแทนกล่องลายทางทันที

ทำซ้ำแบบนี้กับทุกจุดที่ยังเป็นกล่องลายทาง (ในหน้าแรกมีทั้งหมด 3 จุด)

### แบบที่ 2 — รูปผลงานในหน้า Hall of Frame (ง่ายกว่ามาก ไม่ต้องแตะโค้ด)

ผลงานแต่ละชิ้นมีโฟลเดอร์รูปของตัวเองเตรียมไว้ให้แล้วที่ `images/projects/<ชื่อผลงาน>/` (ชื่อโฟลเดอร์ตรงกับ `slug` ในไฟล์ `js/projects-data.js`)

1. เอารูปที่จะใช้ไปวางในโฟลเดอร์นั้น ตั้งชื่อไฟล์ตามที่ระบุไว้ในก้อนผลงานนั้น (เช่น `1.jpg`, `2.jpg`, `3.jpg`)
2. เสร็จแล้ว! ไม่ต้องแก้ไฟล์ HTML หรือ JS เลยสักบรรทัด เว็บจะโหลดรูปจาก path นั้นให้เองอัตโนมัติ ทั้งภาพปกบนการ์ดและสไลด์ในหน้ารายละเอียด

อยากใส่มากกว่าที่มีอยู่ตอนนี้ (เช่นอยากได้ 5 รูปแทน 3 รูป) แค่เปิด `js/projects-data.js` แล้วเพิ่ม path รูปใหม่เข้าไปในลิสต์ `images: [...]` ของผลงานนั้น

### แบบที่ 3 — ไอคอนช่องติดต่อท้ายเว็บ (อีเมล/เบอร์โทร/Facebook/Instagram)

เดิมทีเป็นอิโมจิ (✉️ 📱 📘 📸) ตอนนี้เปลี่ยนเป็น `<img>` รอใส่รูปโลโก้ของตัวเองแล้ว วางไฟล์ในโฟลเดอร์ `images/icons/` ตั้งชื่อไฟล์ตามนี้ให้ตรงเป๊ะ:

- `images/icons/email.png` → ไอคอนอีเมล
- `images/icons/phone.png` → ไอคอนเบอร์โทร
- `images/icons/facebook.png` → ไอคอน Facebook
- `images/icons/instagram.png` → ไอคอน Instagram

วางรูปครบ 4 ไฟล์นี้แล้วรีเฟรชหน้าเว็บ ไอคอนจะโผล่มาเองทันที (ไม่ต้องแก้ HTML) จุดนี้ซ้ำอยู่ใน 4 ไฟล์ `.html` แต่ตั้งชื่อไฟล์รูปเหมือนกันหมด เลยวางรูปแค่ 4 ไฟล์ครั้งเดียวก็ขึ้นครบทุกหน้า — ถ้าอยากได้ไฟล์นามสกุลอื่น (เช่น `.svg`) ก็แก้นามสกุลในแอตทริบิวต์ `src=` ของแต่ละไฟล์ `.html` ให้ตรงกับไฟล์จริงด้วย (ค้นหาด้วยคำว่า `contact-icon`)

## อยากแก้ผลงานใน Hall of Frame ทำยังไง (สำคัญที่สุด)

ผลงานทุกชิ้นไม่ได้เขียนอยู่ใน `portfolio.html` หรือ `project.html` แต่อยู่ในไฟล์เดียว คือ `js/projects-data.js`
เปิดไฟล์นี้จะเห็นเป็นก้อนๆ ก้อนละ 1 ผลงาน หน้าตาแบบนี้:

```js
{
  slug: 'csv-chatbot',           // ชื่อรหัส ห้ามซ้ำกับก้อนอื่น
  title: 'CSV Data Search Chatbot',  // ชื่องานสั้นๆ ที่โชว์บนการ์ด
  category: 'Research / AI',     // ป้ายหมวดหมู่
  date: '...',                   // วันที่ / สถานที่
  description: '...',            // คำอธิบายยาวๆ (โชว์เฉพาะหน้ารายละเอียด)
  award: '...',                  // รางวัลที่ได้ (โชว์เฉพาะหน้ารายละเอียด)
  paper: 'files/papers/xxx.pdf', // (ไม่บังคับ) มีปุ่ม "View Full Paper" โผล่ในหน้ารายละเอียด ไม่ใส่ก็ได้ถ้าไม่มี paper
  group: 'mainframe',            // แท็บกรองในหน้า Hall of Frame ใส่ 'mainframe' หรือ 'other-skills' (ดูรายละเอียดหัวข้อด้านล่าง)
  images: ['images/projects/csv-chatbot/1.jpg', ...] // รูปกี่รูปก็ได้
}
```

- แก้ผลงานเดิม → แก้ค่าตรงๆ ในก้อนนั้นได้เลย
- เพิ่มผลงานใหม่ → copy ทั้งก้อนวางต่อท้าย แล้วเปลี่ยนค่าใหม่ (จำ `slug` ให้ไม่ซ้ำ)
- ใส่รูป → เอารูปวางใน `images/projects/<slug>/` ตามชื่อไฟล์ที่ระบุไว้ใน `images` (รูปแรกในลิสต์จะกลายเป็นภาพปกบนการ์ด ที่เหลือรวมเป็นสไลด์ในหน้ารายละเอียดอัตโนมัติ)
- อยากแนบ paper/เอกสาร PDF → ดูหัวข้อ "อยากใส่ปุ่ม View Full Paper ให้ผลงานอื่น ทำยังไง" ด้านล่าง มีขั้นตอนละเอียดครบ

## ปุ่มกรองในหน้า Hall of Frame (Mainframe / Other Skills)

หน้า Hall of Frame มีปุ่มกรองอยู่เหนือการ์ดผลงาน 2 ปุ่ม: **Mainframe** และ **Other Skills**

- **Mainframe** = ผลงานสายหลัก (หุ่นยนต์, AI, งานวิจัย/วิศวะ) — เปิดหน้ามาจะเจอแท็บนี้ก่อนเสมอ (ตั้งเป็นค่าเริ่มต้น)
- **Other Skills** = ความสามารถอื่นๆ (เช่น ดนตรี, กีฬา, ขับรถ)

**ตั้งใจไม่มีแท็บ "All" (ดูรวมทุกอย่าง)** เพราะถ้าผสมทั้ง 2 กลุ่มไว้ด้วยกันจะดูรก ไม่เป็นระเบียบ คนที่ไม่กดกรองเองก็จะเห็นแต่ Mainframe (ผลงานหลัก) เป็นค่าเริ่มต้นไปเลย เข้าใจง่ายกว่า

**สำคัญ:** เพราะไม่มีแท็บ All แล้ว **ผลงานทุกชิ้นต้องมีฟิลด์ `group` ที่ถูกต้อง ไม่งั้นจะไม่โผล่ในหน้า Hall of Frame เลย** (หายไปเงียบๆ ไม่มี error เตือน)

### จุดที่ 1 — `category` (ป้ายเล็กบนการ์ด ไม่เกี่ยวกับการกรอง)
อยู่ใน `js/projects-data.js` แต่ละก้อนผลงาน เป็นแค่ข้อความอิสระที่โชว์เป็นป้ายเล็กๆ บนการ์ด (เช่น `'Conference'`, `'competition'`, `'educate'`) แก้ตรงๆ ได้เลย ไม่มีผลต่อแท็บกรอง

### จุดที่ 2 — `group` (ตัวกำหนดว่าไปอยู่แท็บไหน)
อยู่ใน `js/projects-data.js` เหมือนกัน แก้/เพิ่มบรรทัดนี้ในก้อนผลงานที่ต้องการ:
```js
group: 'mainframe',      // ไปอยู่แท็บ Mainframe
// หรือ
group: 'other-skills',   // ไปอยู่แท็บ Other Skills
```

### จุดที่ 3 — ชื่อแท็บ / ลำดับแท็บ / แท็บไหนขึ้นก่อน
อยู่ใน `js/portfolio.js` ค้นหาคำว่า `FILTERS` จะเจอ:
```js
const FILTERS = [
  { key: 'mainframe', label: 'Mainframe' },
  { key: 'other-skills', label: 'Other Skills' }
];
let activeFilter = 'mainframe';
```
- **เปลี่ยนชื่อแท็บที่โชว์** → แก้ข้อความหลัง `label:` (เช่นเปลี่ยน `'Mainframe'` เป็นชื่ออื่น) ส่วน `key:` **ห้ามแก้** ต้องตรงกับค่าที่ใส่ใน `group` ของผลงานเป๊ะๆ ไม่งั้นการกรองจะพัง
- **สลับลำดับว่าปุ่มไหนอยู่ก่อน-หลัง** → สลับตำแหน่งบรรทัดในลิสต์ `FILTERS` นี้ได้เลย เรียงจากบนลงล่าง = ซ้ายไปขวาบนหน้าเว็บ
- **เปลี่ยนแท็บไหนขึ้นเป็นค่าเริ่มต้นตอนเปิดหน้า** → แก้ค่าใน `let activeFilter = 'mainframe';` เปลี่ยนเป็น `'other-skills'` ถ้าอยากให้แท็บนั้นขึ้นก่อนแทน
- **เพิ่มแท็บใหม่** (เช่นแยกดนตรีออกจาก Other Skills) → เพิ่มบรรทัดใหม่ในลิสต์ `FILTERS` เช่น `{ key: 'music', label: 'Music' }` แล้วไปใส่ `group: 'music'` ให้ผลงานที่เกี่ยวข้องใน `js/projects-data.js` (อย่าลืม: ผลงานทุกชิ้นต้องมี `group` ตรงกับ `key` ของแท็บใดแท็บหนึ่งเสมอ ไม่งั้นจะไม่โผล่เลย)

แก้ที่นี่ที่เดียว การ์ดในหน้า Hall of Frame กับหน้ารายละเอียดจะอัปเดตตามให้เองทั้งคู่ ไม่ต้องไปแตะ HTML เลย

## อยากใส่ปุ่ม "View Full Paper" ให้ผลงานอื่น ทำยังไง

ผลงานไหนมี paper/เอกสาร PDF ที่อยากแนบ ทำตามนี้ 2 ขั้นตอน:

**ขั้นตอนที่ 1 — เอาไฟล์ PDF ไปวาง**
1. เอาไฟล์ PDF ไปวางในโฟลเดอร์ `files/papers/` (ถ้ายังไม่มีโฟลเดอร์นี้ สร้างเองได้เลย)
2. ตั้งชื่อไฟล์เป็นภาษาอังกฤษ ไม่มีเว้นวรรค เช่น `nclist2024-paper.pdf` (เว้นวรรคในชื่อไฟล์อาจทำให้ลิงก์พัง)

**ขั้นตอนที่ 2 — เปิด `js/projects-data.js` แล้วเพิ่มฟิลด์ `paper`**
เข้าไปที่ก้อนผลงานที่ต้องการ (ดูวิธีหาก้อนผลงานที่หัวข้อด้านบน) แล้วเพิ่มบรรทัดนี้เข้าไปในก้อนนั้น (จะวางตรงไหนในก้อนก็ได้ ไม่มีผลอะไร):
```js
paper: 'files/papers/nclist2024-paper.pdf',
```
เซฟไฟล์ รีเฟรชหน้าเว็บ ปุ่ม "View Full Paper ↗" จะโผล่ขึ้นในหน้ารายละเอียดผลงานนั้นทันที กดแล้วเปิดไฟล์ PDF ในแท็บใหม่ให้เองอัตโนมัติ — ผลงานไหนไม่ใส่ฟิลด์นี้ ก็จะไม่มีปุ่มนี้เลย (ไม่ต้องลบอะไรเพิ่ม)

**หน้าตา/ขนาดของปุ่ม (เผื่ออยากปรับ)**

ปุ่มนี้อยู่ในไฟล์ `project.html` (ค้นหาด้วยคำว่า `projectPaperBtn`) หน้าตาโค้ดเป็นแบบนี้:
```html
<a href="#" class="btn-solid project-paper-btn reveal" id="projectPaperBtn" target="_blank" rel="noopener">View Full Paper <span class="arrow">↗</span></a>
```
ส่วนขนาด/สไตล์ทั้งหมดกำหนดอยู่ใน `css/style.css` ค้นหาคำว่า `.btn-solid` และ `.project-paper-btn` จะเจอค่าตามนี้:

| จุดที่ปรับ | ค่าปัจจุบัน | อยู่ตรงไหน |
|---|---|---|
| ระยะห่างขอบใน (padding) | `13px 26px` (บน-ล่าง 13px, ซ้าย-ขวา 26px) | `.btn-solid` |
| ขนาดตัวหนังสือ | `0.8rem` (~12.8px) | `.btn-solid` |
| ความหนาตัวหนังสือ | `600` | `.btn-solid` |
| มุมโค้งของปุ่ม | `var(--radius)` = `4px` | `.btn-solid` |
| สีพื้นปุ่ม/ตัวหนังสือ | พื้นขาว (`var(--text)`) ตัวหนังสือดำ (`#000`) | `.btn-solid` |
| ความกว้างปุ่ม | `width: fit-content` (กระชับตามข้อความ ไม่ยืดเต็มคอลัมน์) | `.btn-solid` |
| ระยะห่างจากกล่องรางวัลด้านบน | `margin-top: 4px` (ชิดกับ award เหมือนเป็นเนื้อหาต่อเนื่อง) | `.project-paper-btn` |
| การขยับลูกศร ↗ ตอนชี้เมาส์ | เลื่อนไปมุมขวาบน `3px, -3px` | `.btn-solid:hover .arrow` |

ถ้าอยากให้ปุ่มนี้ใหญ่ขึ้น/เล็กลง ก็ไปแก้ `padding` กับ `font-size` ใน `.btn-solid` ได้ตรงๆ (จะกระทบทุกปุ่มที่ใช้คลาสนี้ทั้งเว็บ ตอนนี้มีแค่ปุ่ม View Full Paper ปุ่มเดียวที่ใช้)

## อยากแก้ข้อความอื่นๆ ต้องไปแก้ไฟล์ไหน

ถ้าจำไม่ได้ว่าข้อความอยู่ตรงไหน เปิดไฟล์ที่เกี่ยวข้องแล้วกด **Ctrl+F** ค้นด้วยคำว่า "ค้นหาด้วยคำว่า" ด้านล่างนี้ จะกระโดดไปเจอเลย

**หน้าแรก (`index.html`)**
- ชื่อใหญ่ "Mr. Panyakorn Singhadoung" → ค้นหาด้วยคำว่า `hero-panel__name`
- คำโปรยใต้ปุ่มไปหน้า Hall of Frame กับ My Profile → ค้นหาด้วยคำว่า `preview-panel__desc` (มี 2 จุด จุดแรกคือ Hall of Frame จุดที่สองคือ My Profile)
- ข้อความท้ายเว็บ (footer) → ค้นหาด้วยคำว่า `footer__tagline`

**หน้า Hall of Frame (`portfolio.html`)**
- หัวข้อกับคำโปรยบนสุดของหน้า → ค้นหาด้วยคำว่า `page-header__title` และ `page-header__desc`
- ผลงานแต่ละชิ้น → ไม่ได้อยู่ไฟล์นี้ ไปแก้ที่ `js/projects-data.js` (ดูหัวข้อด้านบน)

**หน้ารายละเอียดผลงาน (`project.html`)**

- มีแค่ลิงก์ "← กลับไป Hall of Frame" ที่พิมพ์ไว้ในไฟล์นี้ตรงๆ → ค้นหาด้วยคำว่า `project-back`
- ใต้ภาพหลักมีแถบรูปเล็กๆ (thumbnail) ให้กดเลื่อนไปรูปอื่นได้ทันที โชว์ทีละ 5 รูป ถ้ามีเกิน 5 รูปจะเลื่อนตามอัตโนมัติเวลากดดูรูปถัดไป — อยากเปลี่ยนจำนวนที่โชว์พร้อมกัน (จาก 5 เป็นเลขอื่น) ไปแก้ที่ `css/style.css` ค้นหาคำว่า `project-slider__thumb {` แล้วเปลี่ยนเลข `5` ในบรรทัด `flex: 0 0 calc((100% - 4 * 8px) / 5);` (เปลี่ยนเลข 4 เป็น (จำนวนที่ต้องการ - 1) ด้วย)

**หน้า My Profile (`about.html`)**
- หัวข้อกับคำโปรยบนสุดของหน้า → ค้นหาด้วยคำว่า `page-header__title` และ `page-header__desc`

- ส่วนเรื่องเล่าวัยเด็ก (รูปซ้าย เล่นสไลด์โชว์อัตโนมัติ / ข้อความขวา) → ค้นหาด้วยคำว่า `childhood`

  - ใส่ข้อความ → แก้ตรง `<p class="childhood__text">` แทนที่ข้อความ `[Edit here: ...]`

**ระวังจุดนี้:** เมนูบนสุด (navbar) กับข้อมูลติดต่อท้ายเว็บ (footer) ก็อปวางเหมือนกันไว้ในไฟล์ `.html` ทั้ง 4 ไฟล์ ถ้าแก้เมนูหรือเบอร์โทร/อีเมล ต้องไล่แก้ให้ครบทั้ง 4 ไฟล์ ไม่งั้นแต่ละหน้าจะไม่ตรงกัน

## อยากปรับขนาดฟอนต์ ทำยังไง

ขนาดฟอนต์ทั้งเว็บคุมจากไฟล์เดียว คือ `css/style.css` เปิดไฟล์นี้แล้วกด **Ctrl+F** ค้นด้วยชื่อคลาสด้านล่าง จะเจอบรรทัดที่มี `font-size: ...` แก้ตัวเลขตรงนั้นได้เลย

**Navbar (เมนูบนสุด)**
- ชื่อโลโก้ "PANYAKORN" → ค้นหาด้วยคำว่า `.navbar__brand`
- เมนู Home / Hall of Frame / My Profile → ค้นหาด้วยคำว่า `.nav-link {`

**ปุ่มต่างๆ**
- ปุ่มขอบเส้น → ค้นหาด้วยคำว่า `.btn-outline`
- ปุ่มพื้นทึบ → ค้นหาด้วยคำว่า `.btn-solid`

**หัวข้อบนสุดของหน้าย่อย (ใช้ร่วมกันทั้ง Hall of Frame และ My Profile)**
- ป้ายเล็กเหนือหัวข้อ (ถ้ามี) → ค้นหาด้วยคำว่า `.page-header__eyebrow`
- หัวข้อใหญ่ เช่น "Hall of Frame" → ค้นหาด้วยคำว่า `.page-header__title`
- คำโปรยใต้หัวข้อ → ค้นหาด้วยคำว่า `.page-header__desc`

**หน้าแรก (`index.html`)**
- ชื่อ "Mr. Panyakorn Singhadoung" บรรทัดเล็ก/บรรทัดใหญ่ → ค้นหาด้วยคำว่า `.line-sm` และ `.line-lg`
- คำโปรยใต้ชื่อ → ค้นหาด้วยคำว่า `.hero-panel__tagline`
- หัวข้อการ์ดพรีวิว (Hall of Frame / My Profile) → ค้นหาด้วยคำว่า `.preview-panel__title`
- คำโปรยการ์ดพรีวิว → ค้นหาด้วยคำว่า `.preview-panel__desc`
- ข้อความในกล่องลายทาง (ก่อนใส่รูป) → ค้นหาด้วยคำว่า `.media-placeholder p`
- หัวข้อ section ทั่วไป (โชว์ซ้ำหลายหน้า) → ค้นหาด้วยคำว่า `.section__title`

**หน้า Hall of Frame (`portfolio.html`) — การ์ดผลงาน**
- ป้ายหมวดหมู่บนการ์ด → ค้นหาด้วยคำว่า `.project-badge`
- ชื่อผลงานบนการ์ด → ค้นหาด้วยคำว่า `.project-card__title`
- รางวัลที่ได้ → ค้นหาด้วยคำว่า `.project-award`
- วันที่ / สถานที่ → ค้นหาด้วยคำว่า `.project-meta`

**หน้ารายละเอียดผลงาน (`project.html`)**
- ลิงก์ "← กลับไป Hall of Frame" → ค้นหาด้วยคำว่า `.project-back`
- คำอธิบายยาวๆ → ค้นหาด้วยคำว่า `.project-detail__desc`
- ปุ่มลูกศรเลื่อนรูป / ปุ่มปิด (ตอนเปิดรูปเต็มจอ) → ค้นหาด้วยคำว่า `.lightbox__btn` และ `.lightbox__close`

**หน้า My Profile (`about.html`)**
- ย่อหน้าแนะนำตัว → ค้นหาด้วยคำว่า `.about__text`
- ป้ายระดับการศึกษาเล็กๆ → ค้นหาด้วยคำว่า `.edu-level`
- ชื่อโรงเรียน → ค้นหาด้วยคำว่า `.edu-info h4`
- ไอคอน/ชื่อทักษะ (การ์ด Skills) → ค้นหาด้วยคำว่า `.skill-icon` และ `.skill-card h4`
- ป้ายเล็กบนการ์ดไทม์ไลน์ → ค้นหาด้วยคำว่า `.journey-tag`
- หัวข้อ/รายละเอียดในการ์ดไทม์ไลน์ → ค้นหาด้วยคำว่า `.journey-card h4` และ `.journey-card p`

**Footer (ท้ายเว็บ)**
- ข้อความ tagline ตัวใหญ่ → ค้นหาด้วยคำว่า `.footer__tagline`
- แถวข้อมูลติดต่อ (เบอร์/อีเมล) → ค้นหาด้วยคำว่า `.contact-item {`
- ไอคอนหน้าแถวติดต่อ → ค้นหาด้วยคำว่า `.contact-icon`
- ข้อความลิขสิทธิ์เล็กๆ ล่างสุด → ค้นหาด้วยคำว่า `.footer__bottom`

**ระวังจุดนี้:** navbar กับ footer ก็อปวางซ้ำใน 4 ไฟล์ `.html` แต่ CSS ที่คุมขนาดฟอนต์อยู่ไฟล์เดียว (`css/style.css`) เพราะงั้นแก้ที่เดียวจบ ครบทุกหน้าอัตโนมัติ ไม่ต้องไล่แก้ทีละไฟล์เหมือนข้อความ

## อยากเผยแพร่ขึ้นเน็ตฟรี ทำยังไง

**วิธีง่ายสุด — Netlify Drop** (ไม่ต้องสมัครสมาชิกก็ได้)
1. เข้า https://app.netlify.com/drop
2. ลากทั้งโฟลเดอร์ `panyakorn-portfolio` ไปวางในหน้าเว็บ
3. รอแป๊บเดียว จะได้ลิงก์เว็บฟรีทันที (เช่น `random-name-123.netlify.app`)

**ถ้าจะแก้ไขบ่อยๆ ผ่าน Git — GitHub Pages**
1. สมัครบัญชี GitHub ฟรีที่ https://github.com
2. สร้าง repository ใหม่ (เช่นชื่อ `my-portfolio`)
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า repository
4. ไปที่ Settings > Pages เลือก branch `main` แล้วกด Save
5. รอ 1-2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/my-portfolio/`

ทั้งสองวิธีฟรี 100% ไม่มีค่าใช้จ่ายแอบแฝง

## จุดเล็กๆ ที่ควรรู้ไว้

- ฟอนต์ (Noto Sans Thai, Space Grotesk) โหลดจาก Google Fonts ผ่านเน็ต ถ้าอยากให้ใช้แบบ offline ล้วนๆ ต้องโหลดไฟล์ฟอนต์มาเก็บไว้ในเครื่องเอง
- ปุ่มติดต่อในเว็บไม่ได้ส่งฟอร์มอัตโนมัติ (เพราะเป็นเว็บ static) แค่เปิดแอปอีเมล/โทรศัพท์ให้เท่านั้น
