เว็บนี้ทำด้วย HTML + CSS + JS ธรรมดา ไม่มี framework ไม่ต้อง build อะไรทั้งนั้น
เปิดไฟล์ `.html` ในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม (มี VSCode ก็พอแล้ว)

## เว็บมีกี่หน้า อะไรอยู่ตรงไหน

- `index.html` → หน้าแรก
- `portfolio.html` → หน้า **Hall of Frame** (โชว์การ์ดผลงานทั้งหมด)
- `project.html` → หน้ารายละเอียดผลงาน (ไฟล์เดียว ใช้ซ้ำกับทุกผลงาน มีสไลด์รูปในตัว)
- `about.html` → หน้า **My Profile** (แนะนำตัว/ทักษะ/การศึกษา)
- `css/style.css` → คุมหน้าตา สี ฟอนต์ ทั้งเว็บ
- `js/projects-data.js` → **ไฟล์สำคัญ** เก็บข้อมูลผลงานทั้งหมด (ชื่อ คำอธิบาย รางวัล รูป)
- `js/script.js`, `js/portfolio.js`, `js/project.js` → ไฟล์ลูกเล่น ปกติไม่ต้องไปยุ่ง
- `images/` → เอารูปมาวางตรงนี้

## เปิดดูเว็บยังไง

1. เปิดโฟลเดอร์นี้ด้วย VSCode
2. ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ตรงๆ ได้เลย **หรือ**
3. ถ้าอยากเห็นการแก้ไขอัปเดตสดๆ ให้ลง extension **Live Server** ใน VSCode (ฟรี) แล้วคลิกขวาที่ `index.html` เลือก "Open with Live Server"

## อยากใส่รูป ทำยังไง

เว็บนี้มีจุดใส่รูป 2 แบบ วิธีไม่เหมือนกันเป๊ะ ดูตามนี้เลย

### แบบที่ 1 — รูปหลักของหน้าแรก (รูปตัวเอง, รูปพรีวิว 2 บล็อก)

ตอนนี้จุดพวกนี้ยังเป็นกล่องลายทางเทาๆ เขียนบอกไว้ว่าต้องเอารูปไปวางที่ไหน เช่น `[Edit here: add your photo at images/hero.jpg]`

ทำตามนี้ทีละขั้น:
1. เตรียมรูปที่จะใช้ แล้วเปลี่ยนชื่อไฟล์ให้ตรงกับที่กล่องบอกไว้ (เช่น ตั้งชื่อว่า `hero.jpg`)
2. ลากไฟล์รูปไปวางในโฟลเดอร์ `images/`
3. เปิดไฟล์ `.html` ที่เกี่ยวข้อง (เช่น `index.html`) ด้วย VSCode
4. หาโค้ดที่ขึ้นต้นด้วย `<div class="media-placeholder">` แล้วลบทั้งก้อนทิ้ง (ลบยาวไปจนถึง `</div>` ที่ปิดคู่กัน)
5. ใต้ก้อนที่ลบไป จะมีบรรทัดคอมเมนต์แบบนี้อยู่ `<!-- <img src="images/hero.jpg" ...> -->` ให้ลบแค่ `<!--` กับ `-->` ที่ครอบหัวท้ายออก เหลือแค่ `<img src="images/hero.jpg" ...>` เฉยๆ
6. เซฟไฟล์ แล้วรีเฟรชหน้าเว็บ รูปจะโผล่มาแทนกล่องลายทางทันที

ทำซ้ำแบบนี้กับทุกจุดที่ยังเป็นกล่องลายทาง (ในหน้าแรกมีทั้งหมด 3 จุด)

### แบบที่ 2 — รูปผลงานในหน้า Hall of Frame (ง่ายกว่ามาก ไม่ต้องแตะโค้ด)

ผลงานแต่ละชิ้นมีโฟลเดอร์รูปของตัวเองเตรียมไว้ให้แล้วที่ `images/projects/<ชื่อผลงาน>/` (ชื่อโฟลเดอร์ตรงกับ `slug` ในไฟล์ `js/projects-data.js`)

1. เอารูปที่จะใช้ไปวางในโฟลเดอร์นั้น ตั้งชื่อไฟล์ตามที่ระบุไว้ในก้อนผลงานนั้น (เช่น `1.jpg`, `2.jpg`, `3.jpg`)
2. เสร็จแล้ว! ไม่ต้องแก้ไฟล์ HTML หรือ JS เลยสักบรรทัด เว็บจะโหลดรูปจาก path นั้นให้เองอัตโนมัติ ทั้งภาพปกบนการ์ดและสไลด์ในหน้ารายละเอียด

อยากใส่มากกว่าที่มีอยู่ตอนนี้ (เช่นอยากได้ 5 รูปแทน 3 รูป) แค่เปิด `js/projects-data.js` แล้วเพิ่ม path รูปใหม่เข้าไปในลิสต์ `images: [...]` ของผลงานนั้น

### แบบที่ 3 — ไอคอนช่องติดต่อท้ายเว็บ (อีเมล/เบอร์โทร/Facebook/Instagram)

เดิมทีเป็นอิโมจิ (✉️ 📱 📘 📸) ตอนนี้เปลี่ยนเป็น `<img>` รอใส่รูปโลโก้ของตัวเองแล้ว วางไฟล์ในโฟลเดอร์ `images/icons/` ตั้งชื่อไฟล์ตามนี้ให้ตรงเป๊ะ:

- `images/icons/email.png` → ไอคอนอีเมล
- `images/icons/phone.png` → ไอคอนเบอร์โทร
- `images/icons/facebook.png` → ไอคอน Facebook
- `images/icons/instagram.png` → ไอคอน Instagram

วางรูปครบ 4 ไฟล์นี้แล้วรีเฟรชหน้าเว็บ ไอคอนจะโผล่มาเองทันที (ไม่ต้องแก้ HTML) จุดนี้ซ้ำอยู่ใน 4 ไฟล์ `.html` แต่ตั้งชื่อไฟล์รูปเหมือนกันหมด เลยวางรูปแค่ 4 ไฟล์ครั้งเดียวก็ขึ้นครบทุกหน้า — ถ้าอยากได้ไฟล์นามสกุลอื่น (เช่น `.svg`) ก็แก้นามสกุลในแอตทริบิวต์ `src=` ของแต่ละไฟล์ `.html` ให้ตรงกับไฟล์จริงด้วย (ค้นหาด้วยคำว่า `contact-icon`)

## อยากแก้ผลงานใน Hall of Frame ทำยังไง (สำคัญที่สุด)

ผลงานทุกชิ้นไม่ได้เขียนอยู่ใน `portfolio.html` หรือ `project.html` แต่อยู่ในไฟล์เดียว คือ `js/projects-data.js`
เปิดไฟล์นี้จะเห็นเป็นก้อนๆ ก้อนละ 1 ผลงาน หน้าตาแบบนี้:

```js
{
  slug: 'csv-chatbot',           // ชื่อรหัส ห้ามซ้ำกับก้อนอื่น
  title: 'CSV Data Search Chatbot',  // ชื่องานสั้นๆ ที่โชว์บนการ์ด
  category: 'Research / AI',     // ป้ายหมวดหมู่ (ใส่หลายป้ายได้ ดูหัวข้อด้านล่าง)
  date: '...',                   // วันที่ / สถานที่
  description: '...',            // คำอธิบายยาวๆ (โชว์เฉพาะหน้ารายละเอียด)
  award: '...',                  // รางวัลที่ได้ (โชว์เฉพาะหน้ารายละเอียด)
  paper: 'files/papers/xxx.pdf', // (ไม่บังคับ) มีปุ่ม "View Full Paper" โผล่ในหน้ารายละเอียด ไม่ใส่ก็ได้ถ้าไม่มี paper
  group: 'mainframe',            // แท็บกรองในหน้า Hall of Frame ใส่ 'mainframe' หรือ 'other-skills' (ดูรายละเอียดหัวข้อด้านล่าง)
  images: ['images/projects/csv-chatbot/1.jpg', ...] // รูปกี่รูปก็ได้
}
```

- แก้ผลงานเดิม → แก้ค่าตรงๆ ในก้อนนั้นได้เลย
- เพิ่มผลงานใหม่ → copy ทั้งก้อนวางต่อท้าย แล้วเปลี่ยนค่าใหม่ (จำ `slug` ให้ไม่ซ้ำ)
- ใส่รูป → เอารูปวางใน `images/projects/<slug>/` ตามชื่อไฟล์ที่ระบุไว้ใน `images` (รูปแรกในลิสต์จะกลายเป็นภาพปกบนการ์ด ที่เหลือรวมเป็นสไลด์ในหน้ารายละเอียดอัตโนมัติ)
- อยากแนบ paper/เอกสาร PDF → ดูหัวข้อ "อยากใส่ปุ่ม View Full Paper ให้ผลงานอื่น ทำยังไง" ด้านล่าง มีขั้นตอนละเอียดครบ

## อยากให้ผลงานชิ้นเดียวมีป้ายหมวดหมู่หลายป้าย

ฟิลด์ `category` ใน `js/projects-data.js` ใส่ได้ 2 แบบ:

```js
category: 'Conference',                        // ป้ายเดียว
category: ['Conference', 'International'],     // หลายป้าย (ใส่กี่ป้ายก็ได้)
```

- **บนการ์ดหน้า Hall of Frame** → ป้ายจะเรียงข้างกัน ถ้าที่ไม่พอจะตัดขึ้นบรรทัดใหม่เอง
- **บนหัวหน้ารายละเอียดผลงาน** → ป้ายจะต่อกันด้วย ` · ` เช่น `Conference · International`

### ⚠️ ห้ามเขียนแบบนี้เด็ดขาด
```js
category: 'Conference',
category: 'International',   // ผิด! บรรทัดนี้จะทับบรรทัดบนเงียบๆ
```
JavaScript ไม่ยอมให้ชื่อฟิลด์ซ้ำกันในก้อนเดียว มันจะ**เอาบรรทัดล่างทับบรรทัดบน**
แล้ว `Conference` จะหายไปโดยไม่มี error เตือนเลย ต้องใช้แบบลิสต์ `[...]` เท่านั้น

## หน้าใบเซอร์ภาษาเยอรมัน (goethe.html) — หน้าพิเศษเฉพาะตัว

ผลงานส่วนใหญ่กดแล้วไปหน้า `project.html` ที่ใช้ร่วมกัน แต่ใบเซอร์ Goethe มี**หน้าของตัวเองแยกออกมา**
เพราะมี 11 ใบไล่ระดับ ต้องจัดวางเป็นบันได A1 → A2 → B1 ซึ่งหน้ากลางทำไม่ได้

### วิธีใส่รูปใบเซอร์
วางไฟล์ในโฟลเดอร์ `images/certs/goethe/` ตั้งชื่อตามนี้เป๊ะๆ (ขีดกลาง ไม่ใช่จุด):

| โมดูล | ชื่อไฟล์ | โมดูล | ชื่อไฟล์ |
|---|---|---|---|
| A1.1 | `A1-1.jpg` | A2.3 | `A2-3.jpg` |
| A1.2 | `A1-2.jpg` | A2.4 | `A2-4.jpg` |
| A1.3 | `A1-3.jpg` | B1.1 | `B1-1.jpg` |
| A1.4 | `A1-4.jpg` | B1.2 | `B1-2.jpg` |
| A2.1 | `A2-1.jpg` | B1.3 | `B1-3.jpg` |
| A2.2 | `A2-2.jpg` | | |

**ใบไหนยังไม่ได้วางรูป** จะขึ้นกล่องลายทางบอกชื่อไฟล์ที่ต้องวาง และกดขยายไม่ได้ (กันกดแล้วเจอจอเปล่า)
พอวางรูปครบแล้วกล่องจะหายไปเอง กดดูเต็มจอได้ทันที ไม่ต้องแก้โค้ด

**รูปหน้าปกการ์ด** (ที่โชว์ในหน้า Hall of Frame) วางที่ `images/projects/goethe/cover.jpg`

### อยากเพิ่ม/ลดใบเซอร์
เปิด `goethe.html` ค้นหาคำว่า `class="cert"` จะเจอก้อนแบบนี้ ก็อปวางแล้วแก้ได้เลย:
```html
<button type="button" class="cert" data-code="B1.4" data-src="images/certs/goethe/B1-4.jpg">
  <span class="cert__thumb"><img src="images/certs/goethe/B1-4.jpg" alt="Goethe-Zertifikat B1.4"></span>
  <span class="cert__code">B1.4</span>
</button>
```
**ต้องแก้ที่อยู่รูปให้ตรงกันทั้ง 2 จุด** คือ `data-src` กับ `src` ของ `<img>`
แล้วอย่าลืมแก้เลข "11 โมดูล" ในแถบสรุปด้านบน (ค้นหาคำว่า `goethe-stat__num`)

### อยากให้ผลงานชิ้นอื่นมีหน้าพิเศษของตัวเองบ้าง
ใน `js/projects-data.js` ใส่ฟิลด์ `url` ให้ผลงานนั้น:
```js
url: 'ชื่อไฟล์ของคุณ.html',
```
การ์ดจะลิงก์ไปหน้านั้นแทน `project.html` — ผลงานที่ไม่ใส่ฟิลด์นี้ยังใช้หน้ากลางเหมือนเดิม

## ปุ่มกรองในหน้า Hall of Frame (Mainframe / Other Skills)

หน้า Hall of Frame มีปุ่มกรองอยู่เหนือการ์ดผลงาน 2 ปุ่ม: **Mainframe** และ **Other Skills**

- **Mainframe** = ผลงานสายหลัก (หุ่นยนต์, AI, งานวิจัย/วิศวะ) — เปิดหน้ามาจะเจอแท็บนี้ก่อนเสมอ (ตั้งเป็นค่าเริ่มต้น)
- **Other Skills** = ความสามารถอื่นๆ (เช่น ดนตรี, กีฬา, ขับรถ)

**ตั้งใจไม่มีแท็บ "All" (ดูรวมทุกอย่าง)** เพราะถ้าผสมทั้ง 2 กลุ่มไว้ด้วยกันจะดูรก ไม่เป็นระเบียบ คนที่ไม่กดกรองเองก็จะเห็นแต่ Mainframe (ผลงานหลัก) เป็นค่าเริ่มต้นไปเลย เข้าใจง่ายกว่า

**สำคัญ:** เพราะไม่มีแท็บ All แล้ว **ผลงานทุกชิ้นต้องมีฟิลด์ `group` ที่ถูกต้อง ไม่งั้นจะไม่โผล่ในหน้า Hall of Frame เลย** (หายไปเงียบๆ ไม่มี error เตือน)

### จุดที่ 1 — `category` (ป้ายเล็กบนการ์ด ไม่เกี่ยวกับการกรอง)
อยู่ใน `js/projects-data.js` แต่ละก้อนผลงาน เป็นแค่ข้อความอิสระที่โชว์เป็นป้ายเล็กๆ บนการ์ด (เช่น `'Conference'`, `'competition'`, `'educate'`) แก้ตรงๆ ได้เลย ไม่มีผลต่อแท็บกรอง

### จุดที่ 2 — `group` (ตัวกำหนดว่าไปอยู่แท็บไหน)
อยู่ใน `js/projects-data.js` เหมือนกัน แก้/เพิ่มบรรทัดนี้ในก้อนผลงานที่ต้องการ:
```js
group: 'mainframe',      // ไปอยู่แท็บ Mainframe
// หรือ
group: 'other-skills',   // ไปอยู่แท็บ Other Skills
```

### จุดที่ 3 — ชื่อแท็บ / ลำดับแท็บ / แท็บไหนขึ้นก่อน
อยู่ใน `js/portfolio.js` ค้นหาคำว่า `FILTERS` จะเจอ:
```js
const FILTERS = [
  { key: 'mainframe', label: 'Mainframe' },
  { key: 'other-skills', label: 'Other Skills' }
];
let activeFilter = 'mainframe';
```
- **เปลี่ยนชื่อแท็บที่โชว์** → แก้ข้อความหลัง `label:` (เช่นเปลี่ยน `'Mainframe'` เป็นชื่ออื่น) ส่วน `key:` **ห้ามแก้** ต้องตรงกับค่าที่ใส่ใน `group` ของผลงานเป๊ะๆ ไม่งั้นการกรองจะพัง
- **สลับลำดับว่าปุ่มไหนอยู่ก่อน-หลัง** → สลับตำแหน่งบรรทัดในลิสต์ `FILTERS` นี้ได้เลย เรียงจากบนลงล่าง = ซ้ายไปขวาบนหน้าเว็บ
- **เปลี่ยนแท็บไหนขึ้นเป็นค่าเริ่มต้นตอนเปิดหน้า** → แก้ค่าใน `let activeFilter = 'mainframe';` เปลี่ยนเป็น `'other-skills'` ถ้าอยากให้แท็บนั้นขึ้นก่อนแทน
- **เพิ่มแท็บใหม่** (เช่นแยกดนตรีออกจาก Other Skills) → เพิ่มบรรทัดใหม่ในลิสต์ `FILTERS` เช่น `{ key: 'music', label: 'Music' }` แล้วไปใส่ `group: 'music'` ให้ผลงานที่เกี่ยวข้องใน `js/projects-data.js` (อย่าลืม: ผลงานทุกชิ้นต้องมี `group` ตรงกับ `key` ของแท็บใดแท็บหนึ่งเสมอ ไม่งั้นจะไม่โผล่เลย)

## อยากใส่ปุ่ม "View on IEEE Xplore" (ปุ่ม DOI) ให้ผลงานอื่น

ปุ่มน้ำเงินข้างปุ่ม View Full Paper ที่พาไปหา paper **ตัวจริงบนเว็บสำนักพิมพ์**

เปิด `js/projects-data.js` หาก้อนผลงานที่ต้องการ แล้วเพิ่มบรรทัดนี้:

```js
doi: 'https://doi.org/10.1109/waie67422.2025.11381035',
```

**ไม่ใส่ = ไม่มีปุ่ม** ไม่ต้องแตะโค้ดอื่นเลย ระบบลบปุ่มทิ้งให้เอง
ถ้าผลงานชิ้นนั้นไม่มีทั้ง `paper` และ `doi` แถวปุ่มทั้งแถวจะหายไป ไม่เหลือช่องว่างค้าง

### DOI คืออะไร หาได้จากไหน

DOI คือ**รหัสถาวร**ที่สำนักพิมพ์ออกให้ paper แต่ละชิ้น หน้าตาเป็น `10.1109/xxxxx`
ข้อดีคือลิงก์นี้**ใช้ได้ตลอดไป** ต่อให้สำนักพิมพ์ย้ายเว็บ เปลี่ยนที่อยู่ ลิงก์ก็ยังพาไปถูกที่

หาได้จาก:
- อีเมลตอบรับจากงานประชุม
- ค้นชื่อ paper ใน [search.crossref.org](https://search.crossref.org)
- หน้า paper บน IEEE Xplore / ACM / Springer

**⚠️ ต้องใส่แบบเต็ม** `https://doi.org/10.1109/...` อย่าใส่แค่ `10.1109/...` เฉยๆ เพราะจะกดไม่ได้

**⚠️ ข้อความบนปุ่มเขียนว่า "IEEE Xplore" ไว้ตายตัว** ถ้าวันหน้ามี paper กับสำนักพิมพ์อื่น
(ACM, Springer) ต้องไปแก้ข้อความในไฟล์ `project.html` ให้ตรงกับที่ตีพิมพ์จริง

### สีน้ำเงินของปุ่ม

อยู่ที่ `--accent` ใน `:root` ของ `css/style.css` (`#4f9fd4` = สีน้ำเงิน IEEE ที่ทำให้สว่างขึ้น
เพื่อให้อ่านออกบนพื้นดำ — สีต้นฉบับ `#00629b` เข้มเกินไปจนแทบมองไม่เห็น)

เป็น**สีเน้นสีเดียวของทั้งเว็บ** ที่เหลือขาวดำล้วน ถ้าจะเพิ่มสีอื่นให้คิดดีๆ ก่อน

## ระบบเปลี่ยนภาษา TH / EN

ตอนนี้มีปุ่ม **TH / EN** อยู่ **2 หน้า** คือ `about.html` (My Profile) และ `project.html` (หน้ารายละเอียดผลงาน)
กดแล้วข้อความสลับภาษาทันที ไม่ต้องโหลดหน้าใหม่

เว็บจะ**จำภาษาที่เลือกไว้ และใช้ร่วมกันทุกหน้า** — เลือก EN ที่หน้าหนึ่ง เดินไปอีกหน้าก็ยังเป็น EN
(เก็บไว้ในเบราว์เซอร์ของคนดู) ค่าเริ่มต้นคือ **TH**

### อะไรสลับภาษาได้ / อะไรล็อกไว้

| จุด | สลับภาษา? |
|---|---|
| คำโปรย + เรื่องเล่า ในหน้า My Profile | ✅ สลับได้ |
| **รายละเอียดงาน** (description) | ✅ สลับได้ |
| **รางวัล** (award) — ข้อความใต้รายละเอียดงาน | ✅ สลับได้ |
| คำโปรยหน้า Hall of Frame ("This showcases...") | ❌ ล็อกอังกฤษเสมอ |
| **ชื่องาน** (title) | ❌ ล็อก — พิมพ์ภาษาไหนก็แสดงภาษานั้น |
| วันที่ / สถานที่ (date) | ❌ ล็อก |

### หลักการทำงาน (เข้าใจอันนี้อันเดียวพอ)

ข้อความที่สลับภาษาได้ จะเขียนไว้ **2 ชุดคู่กัน** ชุดหนึ่งติด `data-lang="th"` อีกชุดติด `data-lang="en"`
เวลากดปุ่ม เว็บจะซ่อนชุดที่ไม่ได้เลือก แล้วโชว์อีกชุดแทน แค่นั้นเลย

```html
<p class="about__text reveal" data-lang="th">
  ข้อความภาษาไทย...
</p>
<p class="about__text reveal" data-lang="en">
  English text...
</p>
```

### อยากแก้ข้อความในแต่ละภาษา

เปิดไฟล์ของหน้านั้น แล้วกด **Ctrl+F** หาคำว่า `data-lang` จะเจอทุกจุดที่สลับภาษาได้

**หน้า My Profile (`about.html`)** — มี 3 คู่:

| ข้อความไหน | ค้นหาด้วยคำว่า |
|---|---|
| คำโปรยใต้หัวข้อ "About Me" | `page-header__desc` |
| ย่อหน้าแนะนำตัว (Introduction) | `about__text` |
| เรื่องเล่าวัยเด็ก | `childhood__text` |

แต่ละอันจะมีคู่ `data-lang="th"` กับ `data-lang="en"` แก้ข้อความข้างในได้ตรงๆ เลย

### รายละเอียดงาน + รางวัล 2 ภาษา (หน้ารายละเอียดผลงาน)

สองอันนี้**ไม่ได้อยู่ในไฟล์ HTML** แต่อยู่ใน `js/projects-data.js` — แต่ละก้อนผลงานมีฟิลด์คู่กันแบบนี้:

```js
description:   'รายละเอียดภาษาไทย...',
descriptionEn: 'English description...',

award:   'รางวัลภาษาไทย...',
awardEn: 'Award in English...',
```

- แก้ข้อความในฟิลด์ไหน ก็จะเปลี่ยนเฉพาะภาษานั้น
- ฟิลด์ `award` / `awardEn` ใส่ `<br>` (ขึ้นบรรทัดใหม่) และ `<em>...</em>` (ตัวเอียง) ได้ — **ควรใส่ให้เหมือนกันทั้ง 2 ภาษา** หน้าตาจะได้ตรงกัน
- **ถ้าไม่ใส่ `descriptionEn` / `awardEn`** เลย เวลากด EN จะแสดงข้อความภาษาไทยแทน (ไม่ว่าง ไม่พัง)
- ผลงานที่ไม่มีรางวัล ก็ไม่ต้องใส่ทั้ง `award` และ `awardEn` กล่องรางวัลจะหายไปเองอัตโนมัติ
- ผลงานใหม่ที่เพิ่มทีหลัง อย่าลืมใส่ `descriptionEn` กับ `awardEn` ด้วย ไม่งั้นกด EN แล้วจะยังเป็นไทยอยู่

**ข้อควรระวัง:** ต้องแก้ให้ครบทั้ง 2 ภาษา ถ้าแก้แค่ภาษาเดียว อีกภาษาจะยังเป็นข้อความเก่าอยู่

### อยากให้ชื่องาน (title) สลับภาษาได้ด้วย

ตอนนี้**ตั้งใจล็อกไว้** ตามที่ออกแบบกันไว้ — พิมพ์ภาษาไหนก็แสดงภาษานั้นเสมอ
ถ้าวันหลังเปลี่ยนใจอยากให้สลับได้ บอกได้ ทำเพิ่มแบบเดียวกับ `descriptionEn` (เพิ่มฟิลด์ `titleEn`)

### อยากเพิ่มข้อความจุดอื่นให้สลับภาษาได้ด้วย

ก็อปข้อความเดิมมาวางเป็น 2 ก้อน แล้วเติม `data-lang="th"` กับ `data-lang="en"` ต่อท้ายใน tag เปิด เหมือนตัวอย่างข้างบน
ระบบจะจัดการให้เองอัตโนมัติ ไม่ต้องแก้ JS หรือ CSS เพิ่มเลย

**อยากให้หน้าอื่น (เช่น Hall of Frame) มีปุ่มเปลี่ยนภาษาด้วย** → ก็อปก้อนนี้จาก `about.html` ไปวางในหน้านั้น:
```html
<div class="lang-switch reveal" id="langSwitch">
  <button type="button" class="lang-btn" data-set-lang="th">TH</button>
  <button type="button" class="lang-btn" data-set-lang="en">EN</button>
</div>
```
แล้วอย่าลืมทำข้อความในหน้านั้นเป็นคู่ `data-lang` ด้วย

### อยากเปลี่ยนค่าเริ่มต้นเป็นภาษาอังกฤษ

ต้องแก้ **2 ที่** ให้ตรงกัน:
1. `js/script.js` ค้นหาคำว่า `siteLang` → เปลี่ยน `'th'` ท้ายบรรทัดนี้เป็น `'en'`
   ```js
   applyLang(localStorage.getItem('siteLang') || 'th', true);
   ```
2. `about.html` และ `project.html` บรรทัดบนสุด → เปลี่ยน `data-active-lang="th"` เป็น `"en"`
   ```html
   <html lang="th" data-active-lang="th">
   ```

**ทำไมต้องแก้ 2 ที่:** ตัวใน HTML คือภาษาที่แสดงทันทีก่อน JS จะทำงาน ส่วนตัวใน JS คือภาษาที่ใช้หลัง JS ทำงานแล้ว
ถ้าตั้งไม่ตรงกัน จะเห็นข้อความกระพริบเปลี่ยนภาษาตอนเปิดหน้า

## อนิเมชันของเว็บ (ชื่อเลื่อนขึ้น + ม่านเปลี่ยนหน้า)

มี 2 อย่าง ทำด้วย **CSS ล้วน** ทั้งคู่ ถ้า JS พังอนิเมชันก็ยังทำงาน และเนื้อหายังมองเห็นได้ปกติ

### 1. ชื่อบนหน้าแรกเลื่อนขึ้นมาทีละบรรทัด
อยู่ใน `index.html` — แต่ละบรรทัดของชื่อถูกครอบด้วย `<span class="line-mask">` (กรอบซ่อน)
ตัวหนังสือข้างในเริ่มจากใต้กรอบแล้วเลื่อนขึ้นมา ไล่กันทีละบรรทัด

**แก้ข้อความชื่อ** → แก้ข้างใน `<span class="line-lg">` เท่านั้น **ต้องคงโครง `.line-mask` ที่ครอบไว้**
ถ้าลบกรอบออก อนิเมชันจะพัง (ตัวหนังสือจะโผล่มาเฉยๆ ไม่มีจังหวะ)

**อยากเพิ่ม/ลดบรรทัด** → ก็อปทั้งก้อน `<span class="line-mask">...</span>` เพิ่มได้เลย
แต่ถ้าเพิ่มเป็นบรรทัดที่ 4 ต้องไปเพิ่มจังหวะหน่วงเวลาใน `css/style.css` ด้วย (ค้นหาคำว่า `nth-child`):
```css
.line-mask:nth-child(4) > .line-lg { animation-delay: .66s; }
```

**ปรับความเร็ว / จังหวะ** → ใน `css/style.css` ค้นหาคำว่า `lineUp`

| จุดที่ปรับ | ค่าปัจจุบัน | ความหมาย |
|---|---|---|
| ความเร็วต่อบรรทัด | `1s` | ยิ่งมากยิ่งช้า/นุ่ม |
| หน่วงบรรทัด 1 / 2 / 3 | `.30s` / `.42s` / `.54s` | ห่างกัน 0.12s = จังหวะไล่กัน ถ้าอยากไล่เร็วขึ้นให้ลดช่องว่าง |
| ระยะที่ดันลงไปซ่อน | `translateY(130%)` | **อย่าลดต่ำกว่า 130%** ไม่งั้นหัวตัวอักษรจะโผล่ให้เห็นก่อนอนิเมชันเริ่ม |
| เผื่อที่ให้หางตัว y/g | `padding-bottom: 0.26em` | ถ้าลดลง หางตัว y กับ g จะถูกกรอบตัดขาด |

### 2. ม่านเปลี่ยนหน้า
กดลิงก์ในเว็บ → จอค่อยๆ มืดลงแล้วหน้าใหม่เผยขึ้นมา ทำให้ 4 หน้ารู้สึกเป็นเว็บเดียวกัน

โครงสร้าง: `<div class="page-curtain"></div>` อยู่ใต้ `<body>` ของทั้ง 4 ไฟล์
- **ตอนเปิดหน้า** ม่านจางหายเองด้วย CSS (ไม่ต้องรอ JS — ถ้าให้ JS เปิดม่านแล้ว JS พัง จอจะดำค้างทั้งหน้า)
- **ตอนกดลิงก์** `js/script.js` ใส่คลาส `is-leaving` ที่ `<body>` เพื่อดึงม่านกลับมา แล้วค่อยเปลี่ยนหน้า

**ปรับความเร็วม่าน** → ต้องแก้ **2 ที่ให้ตรงกัน** ไม่งั้นจังหวะจะเพี้ยน:
1. `css/style.css` ค้นหา `curtainIn` → ค่า `.32s`
2. `js/script.js` ค้นหา `EXIT_MS` → ค่า `320` (มิลลิวินาที)

### ⚠️ เปิดเว็บแล้วไม่เห็นอนิเมชันเลย ทุกอย่างเด้งขึ้นมาทื่อๆ — แก้ยังไง

**สาเหตุ 99% คือเครื่องปิดอนิเมชันของ Windows ไว้** เบราว์เซอร์จะบอกทุกเว็บว่า "ห้ามเคลื่อนไหว"

**วิธีเปิดกลับ:**
1. กด `Win + I` เปิด Settings
2. ไปที่ **Accessibility** → **Visual effects**
3. เปิดสวิตช์ **Animation effects** ให้เป็น **On**
4. รีเฟรชหน้าเว็บ (ถ้ายังไม่ขึ้น ปิดเปิดเบราว์เซอร์ใหม่)

**เช็กว่าเครื่องปิดอยู่จริงไหม** — เปิดเว็บ กด `F12` ไปแท็บ Console แล้ววางคำสั่งนี้:

```js
matchMedia('(prefers-reduced-motion: reduce)').matches
```
ได้ `true` = เครื่องสั่งปิดอนิเมชันอยู่ / ได้ `false` = ปกติ ควรเห็นอนิเมชันครบ

**หมายเหตุ:** เว็บจะ**ปิดอนิเมชันแล้วแสดงทุกอย่างเลยทันที** ไม่ใช่แค่ย่นเวลาให้เร็วขึ้น
เพราะถ้าแค่ย่นเวลาแล้วอนิเมชันไม่ได้วิ่งจบจริง ตัวหนังสือจะค้างซ่อนใต้กรอบแล้วมองไม่เห็นเลย

## การ์ดพรีวิวตอนแชร์ลิงก์ (Open Graph)

เวลาส่งลิงก์เว็บให้เพื่อนใน LINE / Facebook / Messenger / X มันจะขึ้นเป็นการ์ดสวยๆ มีรูป + ชื่อ + คำโปรย
แทนที่จะเป็นลิงก์เปล่าๆ — ตั้งค่าไว้แล้วครบทั้ง 4 หน้า

**รูปการ์ด:** `images/og-card.jpg` ขนาด 1200×630 (สัดส่วนมาตรฐานของทุกแพลตฟอร์ม)

### อยากเปลี่ยนรูปการ์ด
ทำรูปใหม่ขนาด **1200×630** แล้วเซฟทับไฟล์ `images/og-card.jpg` เลย
(ถ้าใช้ขนาดอื่นการ์ดจะถูกครอปมั่ว โดยเฉพาะรูปแนวตั้ง)

**สำคัญ:** พอเปลี่ยนรูปแล้ว ต้องไปเปลี่ยนเลขท้าย URL รูปด้วย ไม่งั้น LINE/Facebook จะยังโชว์รูปเก่า
เพราะมันจำรูปไว้ตาม URL — เปิดไฟล์ `.html` ทั้ง 4 ไฟล์ ค้นหาคำว่า `og-card.jpg?v=` แล้วเปลี่ยนเลขให้สูงขึ้น
(มี 2 บรรทัดต่อไฟล์ คือ `og:image` กับ `twitter:image` ต้องเปลี่ยนให้ตรงกันทั้งคู่)
```html
<meta property="og:image" content=".../images/og-card.jpg?v=2">
<meta name="twitter:image" content=".../images/og-card.jpg?v=2">
```

### อยากเปลี่ยนข้อความบนการ์ด
เปิดไฟล์ `.html` ของหน้านั้น กด **Ctrl+F** หาคำว่า `og:title` จะเจอบล็อกที่ต้องแก้
แต่ละหน้าต้องแก้ **2 จุดที่เขียนข้อความเหมือนกัน** คือ `og:title`/`og:description` (สำหรับ LINE, Facebook)
และ `twitter:title`/`twitter:description` (สำหรับ X) — ถ้าแก้แค่อันเดียวจะไม่ตรงกัน

### ⚠️ ถ้าย้ายเว็บไปโดเมนอื่น ต้องแก้ตรงนี้ด้วย
`og:image` กับ `og:url` **ต้องเป็น URL เต็ม** (ขึ้นต้นด้วย `https://`) ใส่ path สั้นๆ อย่าง `images/og-card.jpg` ไม่ได้
เพราะระบบพรีวิวของ LINE/Facebook มาดึงรูปจากภายนอก มันไม่รู้ว่าเว็บเราอยู่ไหน
ถ้าย้ายโดเมน ให้ค้นหาคำว่า `panyakorn-pan.github.io` ในไฟล์ `.html` ทั้ง 4 ไฟล์ แล้วเปลี่ยนให้ครบทุกจุด

### แชร์แล้วยังขึ้นการ์ดเก่า / ไม่ขึ้นรูป ทำยังไง
พวก LINE กับ Facebook มันจำการ์ดเดิมไว้ (cache) นานเป็นวัน แก้แล้วไม่เห็นเปลี่ยนทันทีเป็นเรื่องปกติ
ถ้าอยากบังคับให้อัปเดตเดี๋ยวนั้น ใช้เครื่องมือทางการล้าง cache:
- Facebook / Messenger → https://developers.facebook.com/tools/debug/ (วางลิงก์ แล้วกด **Scrape Again**)
- X / Twitter → https://cards-dev.twitter.com/validator
- LINE ไม่มีเครื่องมือล้าง cache ให้ วิธีเลี่ยงคือแชร์ลิงก์แบบต่อ `?1` ท้าย URL (เช่น `...github.io/panyakorn-portfolio/?1`) มันจะนับเป็นลิงก์ใหม่

**หมายเหตุเรื่องหน้ารายละเอียดผลงาน:** หน้า `project.html` ตั้งข้อความการ์ดไว้แบบกลางๆ ("ผลงาน — Panyakorn Singhadoung")
ไม่ได้เปลี่ยนตามชื่องานจริง เพราะชื่องานถูกดึงมาด้วย JavaScript ตอนเปิดหน้า แต่ระบบพรีวิวลิงก์ไม่รัน JavaScript
มันอ่านได้แค่ที่พิมพ์ไว้ในไฟล์เท่านั้น (ข้อจำกัดของเว็บ static ทุกเว็บ ไม่ใช่บั๊ก)

## ⚠️ อัปเดตเว็บแล้วหน้าเว็บเพี้ยน / ระบบภาษารวน — แก้ยังไง

**สาเหตุ:** GitHub Pages สั่งให้เบราว์เซอร์เก็บไฟล์ไว้ 10 นาที (`Cache-Control: max-age=600`)
พออัปเดตเว็บ เบราว์เซอร์ของคนที่เคยเข้ามาแล้วอาจใช้ **HTML ตัวใหม่ปนกับ CSS/JS ตัวเก่า** → หน้าเว็บเพี้ยน

**วิธีป้องกัน (ทำทุกครั้งที่แก้ไฟล์ใน `css/` หรือ `js/`):**

เปิดไฟล์ `.html` ทั้ง 4 ไฟล์ กด **Ctrl+F** หาคำว่า `?v=` จะเจอบรรทัดแบบนี้:
```html
<link rel="stylesheet" href="css/style.css?v=2">
<script src="js/script.js?v=2"></script>
```
**เปลี่ยนเลขหลัง `?v=` ให้สูงขึ้น 1** (เช่นจาก `2` เป็น `3`) ให้เหมือนกันทุกบรรทัดทุกไฟล์ แล้วค่อย push

เลขนี้ไม่มีความหมายอะไรเป็นพิเศษ แค่ทำให้เบราว์เซอร์คิดว่าเป็นไฟล์คนละตัว เลยยอมโหลดใหม่แทนที่จะใช้ของเก่า
(ถ้าแก้แค่ข้อความใน `.html` เฉยๆ ไม่ได้แตะ CSS/JS ก็ไม่ต้องเปลี่ยนเลขนี้)

**ถ้าอยากเช็คว่าเว็บอัปเดตจริงหรือยัง:** กด `Ctrl + Shift + R` (บังคับโหลดใหม่ทั้งหมด) หรือรอ 10 นาทีแล้วรีเฟรชปกติ

## อยากเผยแพร่ขึ้นเน็ตฟรี ทำยังไง

**วิธีง่ายสุด — Netlify Drop** (ไม่ต้องสมัครสมาชิกก็ได้)
1. เข้า https://app.netlify.com/drop
2. ลากทั้งโฟลเดอร์ `panyakorn-portfolio` ไปวางในหน้าเว็บ
3. รอแป๊บเดียว จะได้ลิงก์เว็บฟรีทันที (เช่น `random-name-123.netlify.app`)

**ถ้าจะแก้ไขบ่อยๆ ผ่าน Git — GitHub Pages** ← วิธีที่เว็บนี้ใช้อยู่

โฟลเดอร์นี้เตรียม git ไว้ให้เรียบร้อยแล้ว (มี commit แรกอยู่แล้ว) เหลือแค่ทำตามนี้

### ตั้งค่าครั้งแรก (ทำครั้งเดียวจบ)
1. สมัครบัญชี GitHub ฟรีที่ https://github.com
2. สร้าง repository ใหม่ที่ https://github.com/new
   - ตั้งชื่อ เช่น `panyakorn-portfolio`
   - เลือก **Public** (ต้องเป็น Public ถ้าใช้บัญชีฟรี ไม่งั้น GitHub Pages จะใช้ไม่ได้)
   - **อย่า** ติ๊ก "Add a README file" / .gitignore / license (เพราะในเครื่องมีอยู่แล้ว จะตีกัน)
   - กด **Create repository**
3. หน้าถัดไปจะโชว์ URL ของ repo เช่น `https://github.com/<ชื่อผู้ใช้>/panyakorn-portfolio.git` — copy เก็บไว้
4. เปิด **Git Bash** หรือ **Terminal** ที่โฟลเดอร์นี้ แล้วรัน 2 คำสั่งนี้ (เปลี่ยน URL เป็นของคุณ):
```bash
git remote add origin https://github.com/<ชื่อผู้ใช้>/panyakorn-portfolio.git
git push -u origin main
```
   - ครั้งแรกจะให้ล็อกอิน GitHub ให้ล็อกอินตามปกติ
5. กลับไปหน้า repo บนเว็บ GitHub → **Settings** → เมนูซ้าย **Pages**
   - ช่อง Source เลือก **Deploy from a branch**
   - Branch เลือก **main** และโฟลเดอร์เลือก **/ (root)** → กด **Save**
6. รอ 1-2 นาที รีเฟรชหน้า Pages จะเห็นลิงก์เว็บโผล่มา:
   `https://<ชื่อผู้ใช้>.github.io/panyakorn-portfolio/` ← เอาลิงก์นี้ส่งให้เพื่อนได้เลย

### ทุกครั้งที่แก้เว็บเสร็จ แล้วอยากให้เว็บจริงอัปเดต
รัน 3 คำสั่งนี้ที่โฟลเดอร์นี้ (Git Bash / Terminal):
```bash
git add -A
git commit -m "อธิบายสั้นๆ ว่าแก้อะไร"
git push
```
เสร็จแล้วรอประมาณ 1-2 นาที เว็บจริงจะอัปเดตตามให้เองอัตโนมัติ **ลิงก์ไม่เปลี่ยน** ไม่ต้องลากไฟล์อะไรเลย

- `git add -A` = บอกให้ git เก็บทุกไฟล์ที่แก้ไป
- `git commit -m "..."` = บันทึกเวอร์ชันนี้ไว้ในประวัติ (ข้อความในเครื่องหมายคำพูดเขียนอะไรก็ได้ เอาไว้เตือนตัวเองว่าครั้งนั้นแก้อะไร)
- `git push` = ส่งขึ้น GitHub → เว็บจริงจะอัปเดตตาม

**เช็คสถานะก่อน push** (ไม่บังคับ แต่ดี): รัน `git status` ดูว่าไฟล์ไหนถูกแก้ไปบ้าง

### ข้อดีของวิธีนี้
- มีประวัติทุกเวอร์ชัน ย้อนกลับได้ถ้าแก้พลาด
- ไม่ต้องลากโฟลเดอร์ใหม่ทุกครั้งเหมือน Netlify Drop
- ลิงก์คงที่ตลอด ไม่เปลี่ยน

ทั้งสองวิธีฟรี 100% ไม่มีค่าใช้จ่ายแอบแฝง

## อยากให้ค้นชื่อใน Google แล้วเจอเว็บนี้ (SEO)

**ข่าวดี:** ไม่มีใครในโลกชื่อ "Panyakorn Singhadoung" อยู่บน Google เลย
ไม่ต้องแย่งอันดับกับใคร ขอแค่ Google "รู้จัก" เว็บเรา ก็ขึ้นอันดับ 1 เอง

### ฝั่งโค้ดทำไว้ให้แล้ว (ไม่ต้องแตะ)
| สิ่งที่ทำ | ทำหน้าที่อะไร |
|---|---|
| `sitemap.xml` | แผนผังบอก Google ว่ามีหน้าอะไรบ้าง (16 หน้า) |
| `<link rel="canonical">` | บอกว่าหน้าไหนคือ "ตัวจริง" กัน Google นับซ้ำ |
| JSON-LD `Person` ใน `index.html` | บัตรประจำตัวที่ Google อ่านได้ บอกว่าเว็บนี้เป็นของ *คน* ชื่อนี้ |
| ชื่อไทยใน `<title>` + ท้ายเว็บ + `alt` ของรูป | ให้ค้นด้วยชื่อไทย "ปัณยกร สิงห์ดวง" ก็เจอ |

### ⚠️ สิ่งที่ต้องทำเองครั้งเดียว — สำคัญที่สุด ข้ามไม่ได้
โค้ดข้างบนช่วยได้ก็ต่อเมื่อ Google มาเก็บเว็บเราแล้ว แต่เว็บใหม่ที่ไม่มีใครลิงก์หา
Google จะไม่มีทางเจอเองเลย ต้องไปบอกมันตรงๆ

1. เข้า **[Google Search Console](https://search.google.com/search-console)** → ล็อกอินด้วย Gmail
2. กด **Add property** → เลือกช่อง **URL prefix** (ช่องขวา ไม่ใช่ Domain) → ใส่
   `https://panyakorn-pan.github.io/panyakorn-portfolio/`
3. ยืนยันตัวตนด้วยวิธี **HTML file** → โหลดไฟล์ที่เขาให้มา → เอามาวางในโฟลเดอร์เว็บ → **push ขึ้น GitHub** → รอ 1–2 นาที → กลับไปกด Verify

   > **⚠️ "Ownership verification failed" เกือบทุกครั้งมาจากสาเหตุเดียว: ลืม push**
   > วางไฟล์ในโฟลเดอร์เฉยๆ ไม่พอ เพราะ Google ไม่ได้ดูเครื่องคุณ แต่ไปเปิดเว็บจริง
   > ต้องสั่ง `git add -A && git commit -m "verify" && git push` แล้ว**รอ 1–2 นาที**ให้ deploy เสร็จก่อน
   > เช็คว่าพร้อมหรือยังโดยเปิดลิงก์ไฟล์นั้นบนเว็บจริงในเบราว์เซอร์ — ถ้าเห็นข้อความ `google-site-verification: ...` ค่อยกด Verify
   >
   > **⚠️ ห้ามลบไฟล์ `googlece4ecacc362ac4e9.html`** ถึงจะดูเหมือนไฟล์ขยะบรรทัดเดียว
   > Google กลับมาเช็คเป็นระยะ ถ้าไฟล์หาย = ถูกถอนสิทธิ์ ต้องยืนยันใหม่ทั้งหมด
4. เมนู **Sitemaps** → ใส่ `sitemap.xml` → Submit
5. ช่องค้นด้านบน (URL Inspection) → วาง URL หน้าแรก → กด **Request Indexing**

เสร็จแล้วรอ **3 วัน – 2 สัปดาห์** เช็คความคืบหน้าโดยค้นใน Google ว่า
`site:panyakorn-pan.github.io/panyakorn-portfolio` ถ้าขึ้นแปลว่าติดแล้ว

### ORCID iD (เลขประจำตัวนักวิจัย)

**`0009-0005-9931-9015`** → https://orcid.org/0009-0005-9931-9015

ผูกกับเว็บไว้แล้วสองทาง: ORCID มีลิงก์ชี้มาเว็บ และเว็บมี ORCID อยู่ใน JSON-LD

### ⚠️ `robots.txt` ใส่ในโปรเจกต์นี้ไม่มีผล
GitHub Pages แบบ project site อ่าน `robots.txt` จาก `panyakorn-pan.github.io/robots.txt`
ซึ่งอยู่นอกโปรเจกต์นี้ เราคุมไม่ได้ — เลยไม่ได้สร้างไฟล์นี้ไว้ (ไม่ได้ลืม)
ไม่ต้องกังวล เพราะ **ค่าเริ่มต้นคือให้เก็บทุกหน้าอยู่แล้ว** และ sitemap ส่งตรงผ่าน Search Console ได้เลย

### ⚠️ เพิ่มผลงานใหม่แล้ว อย่าลืมแก้ `sitemap.xml`
เพิ่มก้อนใหม่ใน `js/projects-data.js` แล้ว ให้เปิด `sitemap.xml` เพิ่มบรรทัดนี้ด้วย
(เปลี่ยน `ชื่อ-slug` เป็นค่า `slug:` ที่ใส่ไว้):

```xml
<url><loc>https://panyakorn-pan.github.io/panyakorn-portfolio/project.html?slug=ชื่อ-slug</loc><lastmod>2026-08-01</lastmod><priority>0.8</priority></url>
```

ถ้าลืม เว็บยังใช้งานได้ปกติทุกอย่าง แค่ Google จะรู้จักหน้านั้นช้ากว่าเดิม
